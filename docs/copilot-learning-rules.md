# 🤝 Copilot Learning Rules

Copilot is a partner, not a replacement.

## Rules For Healthy Learning

1. Type first for 3-5 minutes before accepting suggestions.
2. Accept small chunks unless you can explain a full block line by line.
3. Test every accepted chunk immediately.
4. Rewrite one accepted idea from memory.
5. Document your understanding in README after each drill.

## When To Pause Copilot

Pause suggestions temporarily when:
- You are practicing syntax recall.
- You can predict the next 3-5 lines yourself.
- You are fixing a bug and need deep focus.

## Reflection Prompt

At the end of each drill, answer:
- Which line was mine?
- Which line was suggested?
- Why does this code work?
- What would break if I changed one key variable?
