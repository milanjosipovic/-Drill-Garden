# 🌞 Morning Routine Template (45 Minutes)

A gentle, consistent start that builds confidence one day at a time.

## 1. 🌱 Warm-Up Recall (0-5 min)

- Type a basic HTML skeleton from memory.
- Add one CSS class and style it.
- Write one JavaScript function and call it.

Prompt to self:
- What syntax felt easy today?
- What syntax felt fuzzy today?

## 2. 🍃 HTML5 Drill (5-20 min)

Focus examples:
- Semantic landmarks (`header`, `main`, `section`, `footer`)
- Form labels and input structure
- Accessible heading structure

Definition of done:
- Structure is valid and readable.
- Landmarks are meaningful.

## 3. 🪴 CSS3 Drill (20-35 min)

Focus examples:
- Flexbox or Grid layout
- Consistent spacing scale
- Hover/focus states
- One responsive breakpoint

Definition of done:
- Layout remains usable on mobile and desktop.

## 4. 🌸 JavaScript Drill (35-45 min)

Focus examples:
- Query elements
- Handle events
- Update state
- Render to UI

Definition of done:
- A clear user action causes a clear UI update.

## 5. 🌼 Reflection (2-3 min after coding)

Write in drill README:
- What I typed myself
- What Copilot suggested
- One bug I hit and how I fixed it
- One thing to revisit tomorrow
