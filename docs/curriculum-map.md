# 🌿 Curriculum Map

This map uses a spiral approach: repeat core ideas with slightly higher complexity each week.

## Week 1: Seed Stage 🌱

- HTML: semantic structure, headings, lists, links
- CSS: selectors, spacing, colors, typography basics
- JS: variables, functions, events, simple DOM updates

## Week 2: Root Stage 🍃

- HTML: forms, labels, inputs, validation basics
- CSS: Flexbox, card layouts, responsive breakpoint
- JS: arrays, objects, looped rendering

## Week 3: Stem Stage 🪴

- HTML: reusable page patterns and accessibility checks
- CSS: Grid, component states, visual hierarchy
- JS: CRUD basics (add/remove/edit), filter/search patterns

## Week 4: Bloom Stage 🌸

- Combine HTML/CSS/JS in mini projects
- Add localStorage for persistence
- Write short architecture notes in README

## Daily Difficulty Model

- Starter: 1 tiny task
- Core: 1 complete drill
- Stretch: optional challenge

## Progress Rule

If two days in a row feel too easy, raise complexity by one step.
If two days in a row feel too hard, reduce scope but keep daily streak alive.
