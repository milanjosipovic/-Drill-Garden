# Daily Workflow Checklist

Use this same flow every morning.

## Commands We Agreed To Use

- `create today’s drill day`
- `update home index for today`

## Daily Steps

1. Start the day and ask Copilot: `create today’s drill day`.
2. Open today's folder in `drills/YYYY-MM-DD/`.
3. Complete the HTML drill:
   - Read that drill `README.md`.
   - Code in `index.html`.
   - Ask: `Review HTML directly`.
   - Add reflection notes in the same `README.md`.
4. Complete the CSS drill:
   - Read that drill `README.md`.
   - Code in `index.html` and `style.css`.
   - Ask: `Review CSS directly`.
   - Add reflection notes in the same `README.md`.
5. Complete the JavaScript drill:
   - Read that drill `README.md`.
   - Code in `index.html` and `script.js`.
   - Ask: `Review JS directly`.
   - Add reflection notes in the same `README.md`.
6. After all 3 drills are reviewed and fixed, ask Copilot: `update home index for today`.
7. Verify the new day links from the home dashboard in `index.html`.
8. Commit and push to GitHub.
9. Confirm GitHub Pages shows the new drill links.

## Definition Of Done (Daily)

- One completed HTML drill
- One completed CSS drill
- One completed JavaScript drill
- Reflection notes added in each drill README
- Home `index.html` updated for today
- Changes pushed to GitHub

## Notes

- You build the drills locally.
- Copilot scaffolds, reviews, and updates the home index on request.
- Manual home index editing is optional; use `update home index for today`.
