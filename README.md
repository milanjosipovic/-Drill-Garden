## 📖 About & Narrative

The **Drill Garden** is my personal digital playground and knowledge vault. Hand-crafted from scratch using semantic web standards, this space acts as my public digital garden where I synthesize concepts from web development courses, active recall drills, and reflections on mental health and focus.

Rather than relying on heavy frameworks or static site generators, every exercise and document is structured by hand to maintain full control over the markup, styling, and open web integration.

---

## 🛠️ Tech Stack & Protocols

* **Architecture:** Hand-coded Vanilla Web Architecture
* **Languages:** Semantic HTML5, Pure CSS3, Vanilla JavaScript
* **Hosting:** GitHub Pages
* **Open Protocols:** Microformats2 (`h-card`, `h-entry`), Webmentions, RSS
* **Workflow:** PARA Method organization & progressive refinement
