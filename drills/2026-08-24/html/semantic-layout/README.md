# Semantic Layout Drill

## Goal

Build a semantic page from scratch using these exact elements:

- `header`
- `nav`
- `main`
- `section`
- `article`
- `aside`
- `footer`

## Start

1. Open `index.html`.
2. Inside `<body>`, create one `header`.
3. Inside `header`, add one `h1` and one `nav`.
4. After `header`, create one `main`.
5. Inside `main`, add one `section`.
6. Inside `section`, add one `article` with one `h2` and one `p`.
7. Still inside `main`, add one `aside` with one `h2` and one `ul`.
8. After `main`, add one `footer` with one `small`.
9. Keep the page plain HTML first. Do not style it yet.

## Reflection

- What I typed myself: All.
- What Copilot suggested: To structure sematic page with making header, main and footer sibling under body.
- What I learned: New tag named `small`. Inside `nav` tag goes `a` tag which behaves like link.
