# Flexbox Card Drill

## Goal

Build a card layout with CSS Flexbox.

## Start

1. Open `style.css`.
2. Center the page with Flexbox.
3. Style the card container with padding, border radius, and shadow.
4. Use Flexbox for the action row and add a gap.
5. Give the normal button and ghost button different styles.
6. Keep the card readable on smaller screens.

## Check

- The card is centered on the page.
- The action buttons sit in one aligned row.
- The card keeps good spacing and contrast.
