# Flexbox Feature Card Drill

## Goal

Build a feature card layout with CSS Flexbox.

## Start

1. Open `style.css`.
2. Center the layout with Flexbox or grid.
3. Style the card container with spacing, border radius, and shadow.
4. Use Flexbox for the header row, stats row, and actions row.
5. Make the stats wrap cleanly on small screens.
6. Give the badge and buttons clear visual contrast.

## Check

- The card is centered.
- The rows align with Flexbox.
- The stats and actions stay readable on smaller screens.
