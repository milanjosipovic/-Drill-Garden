# Task Array Board Drill

## What You Are Building

You are building a small task board app.

- Type a task in an input.
- Add it to a visible list.
- Remove tasks from the list.
- Optionally filter tasks by text.

The important rule: the visible list should be rendered from JavaScript array state.

## Why This Drill Exists

- Practice array updates (`add`, `remove`, and optional `filter`).
- Practice rendering a list from state.
- Practice connecting form events to UI updates.

## Goal

Build a task board with JavaScript array updates, filtering, and DOM rendering.

## Start

1. Open `script.js`.
2. Create a `tasks` array and one render function.
3. Select the input, form or button, and list elements.
4. Render each task as an `li`.
5. Add a handler to insert a new task into the array.
6. Add a handler to remove a task from the array.
7. Re-render the list after each update.
8. If you want, add a simple filter input as a stretch task.

## Check

- Tasks are controlled by array state.
- DOM updates happen through render logic.
- Add and remove flows both work.
